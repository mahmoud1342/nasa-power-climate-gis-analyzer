# Code of Conduct

We want this project to be a welcoming, respectful place for everyone.

- Be kind and constructive. Disagree with ideas, not people.
- No harassment, discrimination, personal attacks or unwelcome sexual attention.
- Assume good faith, and help newcomers.
- Scientific accuracy matters: report problems with evidence, and accept corrections graciously.

Maintainers may remove comments, issues or contributions that break these rules.
To report a problem, contact the maintainer, Mahmoud Mohamed Atia, through his GitHub profile.
